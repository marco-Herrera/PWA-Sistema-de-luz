LUMI — Interfaz por apartados
=============================

Archivos:
- index.html: estructura de la interfaz.
- style.css: diseño visual y animaciones.
- script.js: navegación, interacciones, habitaciones, escenas y horarios.
- README.txt: esta guía.

Uso:
1. Extrae el ZIP.
2. Abre index.html con Chrome o Edge.
3. Mantén internet para que carguen las imágenes ilustrativas.

Apartados:
- Inicio: resumen, habitaciones y control rápido.
- Habitaciones: permanece integrado en Inicio.
- Dispositivos: panel de dispositivos/ESP32 de demostración.
- Escenas: selección de ambientes.
- Horarios: permite crear y eliminar horarios locales de demostración.
- Estadísticas: panel de consumo.
- Notificaciones: avisos y actividad reciente.
- Ajustes: preferencias locales.

Nota: la maqueta no guarda habitaciones ni horarios al recargar. El control físico del ESP32 requiere una API/backend conectada.
